## 🇬🇧 English

Repository with the notebooks and exercises I developed in the **Artificial Intelligence Bootcamps** (basic level, 2024, and advanced level, 2025) of the **Talento Tech** program from the Colombian Ministry of ICT (MinTIC), delivered with UTP FaceIT.

### 📚 Contents

| File / Folder | Description |
|---|---|
| `Entrenamiento/` | Training material and practice exercises from the bootcamp |
| `ScikitLearn.ipynb` | Introduction to machine learning with scikit-learn |
| `Act_2_Redes_Neu.ipynb` | Activity 2: neural networks |
| `Act_2_Keras.ipynb` | Activity 2: building models with Keras |
| `convolutional_network.ipynb` | Convolutional neural network (CNN) |
| `Lab_Pandas_Gemini_GOOGLE_API_KEY_Campist...ipynb` | Lab: data analysis with pandas and the Google Gemini API |
| `CSI_de_los_Datos.ipynb` | Data exploration and analysis exercise |
| `Calculadora_Edad.ipynb` | Python exercise: age calculator |

### 🛠️ Technologies

Python · Jupyter Notebook · Google Colab · pandas · scikit-learn · Keras · Google Gemini API

### ▶️ How to use

1. Open any `.ipynb` file in this repository.
2. Click **Open in Colab** (or download it and open it in Jupyter).
3. Run the cells in order.

> ⚠️ Notebooks that use the Gemini API require your own API key. Never share it publicly: store it in Colab *Secrets*.
